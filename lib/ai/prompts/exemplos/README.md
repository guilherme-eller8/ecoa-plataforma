# Exemplos (few-shot)

Vazio na versão 0, de propósito. Os exemplos nascem das correções do design partner sobre o texto da IA (`npm run lab -- --comparar`).

Um par só entra aqui quando:
1. A família autorizou o reuso (`consentimento.reusoComoExemplo: true` no glossário do livro).
2. Foi anonimizado e revisado à mão: nomes, lugares, datas e episódios identificáveis trocados.
3. Saiu do conjunto usado para avaliar.

Formato (um arquivo .json por par):
{ "entrada": "segmentos S001…", "saida": "texto corrigido", "porque": "o que este par ensina" }
